# lishangan-aria-blog
一个个人DIY缝合怪的作品，基于 Vue 3、FastAPI 、PostgreSQL 和Astro的现代化个人博客管理系统。具有未来感 UI 设计、实时评论弹幕、后台管理和邮件通知等功能。A self-assembled personal project built with Vue 3, FastAPI, PostgreSQL and Astro — a modern blog management system. It features futuristic UI design, real-time comment bullet screens, backend management, email notifications and more.
